What you will learn

  • An origin is the combination of scheme, host, and port.
  • SOP restricts one origin from reading another origin's DOM and responses.
  • CORS lets a server grant selected cross-origin response access.
  • A preflight can stop the actual request before it is sent.

https://example.com:443 is an origin. A different scheme, host, or port means a different origin.

SOP does not make every cross-origin request disappear. It limits what JavaScript can read or manipulate.

A CORS-safelisted request can send the actual request first. Other cross-origin requests use an OPTIONS preflight.

If preflight is rejected, the actual request is not sent. A Fetch API TypeError alone cannot prove the cause.
